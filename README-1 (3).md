# Legal Ease

A simple student-friendly legal information website built with HTML, CSS and JavaScript.

## Files

- `index.html` - Main webpage
- `style.css` - Website design and responsive layout
- `script.js` - Simple legal-topic assistant

## How to run

Open `index.html` in a web browser.

## GitHub upload

Upload all three files to the repository and commit the changes.

## Note

This is an educational project. The information assistant provides general information and does not provide legal advice.
